# GROUPE-STAGE-4

Ce projet est une page web de présentation statique réalisée en HTML et CSS.

## Description

Cette page présente un profil, une introduction, une section "About" ainsi qu’un pied de page structuré. Elle a été conçue pour servir de support de présentation visuelle simple et propre.

## Structure du projet

- index.html : structure principale de la page
- style.css : styles et mise en page
- Assets/ : images et ressources utilisées

## Utilisation

1. Ouvrir le fichier index.html dans un navigateur.
2. Ou utiliser un serveur local si vous souhaitez tester la page dans un environnement plus proche d’un site web.

## À propos

Ce projet a été réalisé dans le cadre d’un stage de groupe et mis à jour avec des commentaires détaillés dans les fichiers HTML et CSS.
